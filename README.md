# Customer Churn Analysis

## Project Overview

An interactive Power BI dashboard developed to analyze customer churn and identify patterns affecting customer retention.

## Tools & Technologies

- Power BI
- Microsoft Excel
- Power Query

## Key KPIs

- Total Customers
- Churned Customers
- Churn Rate
- Retention Rate

## Key Analysis

- Churn by contract type
- Churn by customer tenure
- Churn by customer type
- Churn by security services
- High-risk customer segments

## Key Insights

- Identified customer segments with higher churn rates.
- Analyzed the relationship between customer tenure and churn.
- Identified key patterns associated with customer retention.
